# 🚀 Borderland SSC Tracker Pro

A modern **offline Progressive Web App (PWA)** built for the **Borderland SSC 65-Day Integrated Study Plan**.

The goal of this project is to provide an interactive study companion for SSC aspirants with daily targets, progress tracking, revision planning, analytics, and productivity tools.

---

## 📅 Study Planner
- Complete 65-Day Borderland Study Plan
- Daily Targets
- Interactive Calendar
- Mega Test Schedule
- CCT Reminders

- Overall Progress

- Remaining Days
- Today's Target
